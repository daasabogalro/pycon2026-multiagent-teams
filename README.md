# Multi-Agent Teams in AI-Assisted Development

Hands-on material for the PyCon Colombia 2026 workshop — a 2-hour session on multi-agent coding, live.

We'll split into two teams (Claude Code and Hermes), run the same exercises on both tools, then swap so everyone gets a feel for both. No slides in this repo — just the prompts and setup you need to follow along.

## Setup

Follow the guide when the time comes to use one or the other:

- [claude-code-install-instructions.md](claude-code-install-instructions.md)
- [hermes-install-instructions.md](hermes-install-instructions.md)

You'll need an Anthropic API key during the setups, we will provide it during the workshop.

## Structure

One folder per hands-on, one per tool:

- `claude-hands-on-1` / `hermes-hands-on-1` — build an app from scratch
- `claude-code-hands-on-2` / `hermes-hands-on-2` — second round, code review exercise

We also added the `settings.json` for Claude Code inside the `run-folder` folders, so you use the prompt from those folders when necessary. Each has a `prompt.md` with what to run. As the workshop progresses, we'll drop our own results as well, so don't worry too much if it doesn't work on your end.
